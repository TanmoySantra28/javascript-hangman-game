# Hangman Game using JavaScript

A fun and interactive Hangman game built using HTML, CSS, and JavaScript.

## About the Game

Hangman is a classic word-guessing game where the player tries to guess a hidden word one letter at a time. For every wrong guess, a part of the hangman is drawn. The game ends when:
- The player correctly guesses the word (Victory).
- The player makes 6 incorrect guesses (Game Over).

## Features

- Randomly generated word and hint on each play.
- Interactive on-screen keyboard.
- Animated hangman graphics that update with wrong guesses.
- Modal pop-up for game over or win message.
- Fully responsive design for mobile and desktop.

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)

## Getting Started

### Prerequisites

To run this project, you only need a web browser.

### Installation

1. Clone the repository or download the ZIP file:

   ```bash
   git clone https://github.com/TanmoySantra28/javascript-hangman-game.git
   ```

2. Navigate to the project directory:

   ```bash
   cd javascript-hangman-game
   ```

3. Open the `index.html` file in your web browser.

## Files

- `index.html`: The main HTML file containing the structure of the game.
- `style.css`: The CSS file for styling the game.
- `script.js`: The JavaScript file containing the logic for hangman game.
- `word-list.js`: The JavaScript file containing the word list.
